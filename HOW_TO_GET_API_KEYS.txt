❓ TROUBLESHOOTING:

Q: I already created a key on 8/21/21, can I use it?
A: Only if you saved the API Secret at that time. 
   If you lost it, create a new one (you can have multiple keys).

Q: Can I recover the old API Secret?
A: No. Kraken doesn't store it. You must create a new key pair.

Q: Will creating a new key affect my old one?
A: No. You can have multiple API keys. The old one stays active.

Q: Should I delete my old key?
A: Yes, if you're not using it. Click "Remove" next to it.

Q: What if I see "Invalid API Key" error?
A: Double-check you copied BOTH the key and secret correctly.
   Make sure there are no extra spaces.
